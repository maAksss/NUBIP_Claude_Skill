# NUBiP Claude Skill

Цей репозиторій містить комплекс навчальних матеріалів, готових шаблонів та спеціалізованих навичок (Claude Skills), створених для автоматизації підготовки й стандартизованого оформлення академічних робіт і презентацій Національного університету біоресурсів і природокористування (НУБіП) України за допомогою штучного інтелекту Claude.

## Опис файлів репозиторію

| Файл | Опис |
| :--- | :--- |
| `index.html` | Головний інтерактивний веб-посібник «Покроково: як навчити Claude оформлювати Word і PowerPoint» зі світлим сучасним дизайном (Modern Clean). |
| `design1.html` | Альтернативний варіант оформлення посібника у стилі **Dark Neon Cyberpunk** (темна тема з неоновими акцентами). |
| `design2.html` | Альтернативний варіант оформлення посібника у стилі **Warm Editorial** (тепла журнальна естетика з елегантною типографікою). |
| `design3.html` | Альтернативний варіант оформлення посібника у стилі **Playful Bento** (модульний блоковий інтерфейс Bento у м'яких пастельних тонах). |
| `nubip-presentation.skill` | Пакунок навички Claude Skill для автоматичної генерації презентацій PowerPoint згідно з брендбуком та структурою НУБіП. |
| `nubip-mkr-docx.zip` | Пакунок навички Claude Skill для автоматичного форматування модульних контрольних робіт (МКР) та звітів у форматі Word (.docx) за стандартами університету. |
| `Шаблон_Презентація_НУБІП.pptx` | Офіційний базовий шаблон презентації Microsoft PowerPoint у фірмовому стилі НУБіП. |
| `Навчальне_відео_Claude_Skill.mp4` | Покрокова відеоінструкція з демонстрацією встановлення навичок Claude та генерації презентацій і текстових матеріалів. |
| `README.md` | Головна документація репозиторію з коротким описом проєкту та переліком файлів. |
